# Security policy

## Reporting a vulnerability

Please report vulnerabilities privately through GitHub's private advisories:
**https://github.com/skinnx/z/security/advisories/new**

Don't open a public issue for a vulnerability. Include what you found, how to reproduce it and the version or commit you tested. You will get an answer in the advisory thread.

## Supported versions

Fixes go into the latest version on the default branch.

## Threat model

[docs/security.md](docs/security.md) describes who can reach what, what is encrypted at rest, the approval pipeline and the network guards.
